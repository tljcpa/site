这是一所高校办的具身智能比赛。初赛是 LIBERO Object 仿真任务，用官方给的 LeRobot 数据做模仿学习，看隐藏任务上的成功率，训练必须在官方指定的天数智芯（国产 GPU）平台上完成。我最后没有可报的名次，计划中的 π0.5 也没训成，实际跑起来的是 π0 的 LoRA 续训，停在第 7500 步。

## 数据

官方数据包是 LeRobot v2.1 格式，536,398,466 字节。内容是 Franka 机械臂把 10 个物体搬进篮子，一共 454 条 episode、66,984 帧、908 段视频，20 FPS，每条 114 到 254 帧。主相机和腕部相机各一路，256×256 RGB，AV1 编码。状态 8 维，动作 7 维，包括位置、轴角旋转和夹爪。

不同 VLA 代码库要的数据格式不一样，所以我准备了 LeRobot 转 OpenDM 和 LeRobot 转 RLDS 两个转换工具，转换时不改数值、符号、尺度和顺序。模仿学习对数据很敏感，一帧错位或者悄悄少几条都可能让后面的训练结果没法解释，所以 OpenDM 这一路我要求做全量核验。66,984 行逐一和原始 parquet 精确比对，133,968 张 JPEG 全部实际加载一遍，转换时传入预期的帧数和 episode 数，对不上就报错。结果是 454 个 episode、66,984 帧，没有主动排除，也没有来历不明的丢帧。

核验时还发现 OpenDM 内置的 `libero_object` 注册是按 7 维状态写的，而这份数据是 8 维，必须改用 `libero_pi0_all` 注册。RLDS 这一路写好了转换和校验，但 TFDS 数据集还没真正生成。

## 让训练在国产 GPU 上跑起来

平台节点上原本的 PyTorch 是 NVIDIA CUDA 发行版，和天数 GPU 不兼容。我换用了节点自带的 COREX PyTorch，只改训练进程的库路径和 Python 搜索路径，不动系统安装。

换完先跑一次 10 步的 smoke 测试。第一次在导入 LeRobot 时因为缺 `pyserial` 退出，补上后第二次通过，第 6000 到 6010 步退出码 0，10 步 loss 都是有限值。

续训的起点是之前一轮留下的第 6000 步 LoRA 检查点。续训最怕的是看起来接上了，其实某部分被重新初始化，所以恢复时我逐项确认过。基模加载了 778 个张量，没有缺失或多余的键；adapter 的 514 个张量逐一比对相等且有限，可训练参数 26,674,688 个；optimizer、RNG、scheduler 都真正恢复了。

正式续训每 100 步保存一次 adapter、optimizer、RNG、scheduler 和配置，每次都写一份 `complete.json`，记下每个文件的字节数和 SHA256，以它作为保存完成的依据。平台机器随时可能被回收，所以另写了备份脚本，每 60 秒检查一次新检查点，传回本地后重新计算 SHA256 比对。到第 7500 步为止的检查点都在本地校验通过了。中途还发现交接记录里有个 SHA256 写反了一处字符，对远端原包和传输副本分别重算后改正。

## 训练记录

smoke 用 batch 4，第 6001 步 loss 0.8123，第 6010 步 0.5044，每步约 2.7 到 3.1 秒。正式续训用 batch 16 单卡，第 6011 步 loss 0.5166，第 6024 步 0.5878，每步约 9.6 到 9.85 秒。显存约 20GB（卡是 32GB），没有 OOM，GPU 利用率 98% 到 100%。第 7395 步最近的 loss 是 0.2932。原计划训到 9000 步，实际停在 7500 步。这些都是单步 loss，有波动，只能看趋势。

## 为什么停在 7500 步

我的目标本来是 π0.5。训练跑了一段后我回头核对配置，发现恢复的基模配置写的是 `policy.type=pi0`。确认选错之后，我主动停掉了训练，最后一个完整检查点是第 7500 步。继续训一个不是目标的模型，只会接着浪费算力。

之后准备了两条替代路线，DM0.5（OpenDM）的 LoRA 微调和 TurboVLA。DM0.5 的数据已经转好，但官方权重下载到约 0.60/11.66GB 时超时，GPU smoke 和训练都没启动。TurboVLA 只做到核对源码和写好训练脚本，没生成数据，也没训练。

## 结果怎么看

我没有在仿真里评测续训后的模型，所以手上没有成功率数字。loss 下降不等于任务成功率提升，这一点我很清楚。实际训的是 π0，从选错基模到发现，浪费了一段算力。RLDS 转换和两条替代路线都停在准备阶段，也没做任何对照实验。没有名次，也没有提交成绩可以引用。
